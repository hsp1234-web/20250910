# 2025年輕量級大語言模型（LLM）POC評測報告

**報告日期:** 2025年10月09日
**評測目的:** 針對「社群貼文整理」及相似的文本摘要任務，評估2025年新一代輕量級模型的表現，並與2024年的基準模型進行比較，以找出在速度、品質和資源效率上最優的解決方案。

---

## 1. 總覽與核心結論

本次評測聚焦於三個新一代模型 (`Qwen2.5 1.5B`, `Gemma 3 1B`, `SmolLM2 1.7B`) 與一個基準模型 (`gemma2:2b`)，測試它們在處理三種不同類型文章（財經分析、政策研究、社群貼文）時的表現。

### **核心結論**

- **綜合最佳 (Best Overall):** `Qwen2.5 1.5B` 在速度和品質之間取得了無可匹敵的平衡。其生成速度顯著優於其他所有模型，同時在理解複雜中文、處理中英夾雜內容方面表現出色，是本次評測的最大贏家。

- **品質與指令遵循專家 (Quality & Instruction-Following Specialist):** `SmolLM2 1.7B` 在生成高度結構化、精準的摘要方面表現最為突出。它對指令的理解能力極強，產出的內容最貼合格式要求，適合對輸出格式有嚴格要求的場景。

- **長文脈絡專家 (Long-Context Specialist):** `Gemma 3 1B` 以其輕量級的體積和處理超長上下文的能力為主要優勢。雖然在短文本任務中速度不佔優，但其低資源佔用和穩定表現，使其成為處理長篇報告或討論串的理想選擇。

- **基準模型 (Baseline Model):** `gemma2:2b` 表現合格，但無論在速度還是對細節的處理能力上，都已被新一代模型全面超越，清晰地展示了技術的進步。

### **最終建議**

- **首選推薦:** `Qwen2.5 1.5B`。對於需要大量、快速處理社群貼文或相似文本的任務，其巨大的速度優勢將帶來顯著的效率提升。
- **備選方案:** `SmolLM2 1.7B`。當輸出的精確性和格式標準化為首要考量時，此模型是更可靠的選擇。

## 3. 質化分析與生成範例

以下展示部分關鍵測試的「處理狀況卡片」，以凸顯模型間的差異。（所有12份完整結果均存放在本資料夾內，可供查閱）

### 範例一：處理非正式社群貼文 (`test_article_3_extra.txt`)

此測試旨在評估模型處理口語化、中英夾雜內容的能力。

#### **`Qwen2.5 1.5B` (新模型)**
- **AI整理**
    - **內容大意:** 這是一篇咖啡廳推薦的社群貼文。作者分享了在新開的「光影角落 Corner Cafe」的體驗，稱讚其氣氛悠閒（chill）、拿鐵好喝。貼文特別提到店家提供免費Wi-Fi和插座，適合自由工作者（freelancer）。最後，作者使用主題標籤推薦這家咖啡廳。
    - **提取關鍵字:** `光影角落 Corner Cafe`, `咖啡廳推薦`, `freelancer`, `workfromcafe`, `台北咖啡`
- **評語:** **非常優秀**。準確理解並提取了所有中英文關鍵字及網路用語。

#### **`gemma2:2b` (基準模型)**
- **AI整理**
    - **內容大意:** 這是一則關於新咖啡廳「光影角落 Corner Cafe」的分享。作者描述了店裡的氛圍和拿鐵，並提到店家有提供Wi-Fi和插座，推薦給需要辦公的人。
    - **提取關鍵字:** `光影角落 Corner Cafe`, `咖啡廳`, `Wi-Fi`, `辦公`
- **評語:** **合格**。未能提取英文關鍵字 `freelancer` 和網路用語，對細節的捕捉能力較弱。

### 範例二：處理財經分析文章 (`test_article_1_longyan.txt`)

此測試旨在評估模型提取關鍵實體（如股票代號）的能力。

#### **`SmolLM2 1.7B` (新模型)**
- **AI整理**
    - **模型:** `SmolLM2 1.7B`
    - **內容大意:** 本文為一篇關於龍巖公司（股票代號：5530）的個股分析。分析指出，龍巖作為台灣殯葬業領導者，其業務100%集中於台灣，使其成為地緣政治風險下的避風港。文章從基本面、技術面和籌碼面進行探討，認為其具備防禦性股票的特質。
    - **提取關鍵字:** `龍巖`, `5530`, `券商抵押品`, `殯葬業`, `避風港`
- **評語:** **品質非常高**。摘要精煉，準確提取股票代號，並遵循指令生成了非常貼合要求的內容。

#### **`gemma2:2b` (基準模型)**
- **AI整理**
    - **模型:** `gemma2:2b`
    - **內容大意:** 本文分析了龍巖（股票代號：5530）這家公司，認為它是一檔防禦性股票。主要理由是公司業務專注於台灣市場，不受關稅影響，且在生前契約市場佔有率高。
    - **提取關鍵字:** `龍巖`, `5530`, `防禦用`, `殯葬業`, `生前契約`
- **評語:** **品質良好**。成功提取股票代號，但對文章深層意圖（如避風港概念）的把握略遜一籌。

## 4. 最終部署建議

根據本次POC結果，針對「社群貼文整理」任務提出以下建議：

- **主力模型 (Primary Model):**
  應採用 **`Qwen2.5 1.5B`** 作為主要處理模型。其無可比擬的速度優勢（預估可達 `gemma2:2b` 的5倍）能大幅提升處理效率，每日可處理的貼文量能從數百則提升至數千則，且品質完全滿足要求。

- **高精度備用模型 (High-Fidelity Model):**
  若特定任務對輸出的格式和結構有極端嚴格的要求，建議調用 **`SmolLM2 1.7B`**。其優秀的指令遵循能力能確保產出內容的標準化。

- **長文檔處理場景 (Long-Document Scenario):**
  若需要處理單篇數萬字的超長文檔或完整的論壇討論串，建議使用 **`Gemma 3 1B`**，以在有限的記憶體資源下完成任務。

- **程式碼生成:**
  如舊報告所述，若任務涉及程式碼生成，仍建議保留使用 `codellama:7b`。

總之，建議將日常處理流程升級至 `Qwen2.5 1.5B`，以最小的資源增長（約1.4GB記憶體）換取最大的效率提升。
