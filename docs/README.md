# 文件總覽

此 `docs` 資料夾是專案所有文件的中央存放庫。它旨在提供一個清晰、有組織的結構，以便快速查找和參考所有相關文件。

## 資料夾結構

```
docs/
├── Project_Plans/
├── Research_Reports/
└── System_Documentation/
```

## 資料夾說明

*   **[Project_Plans/](./Project_Plans/)**: 包含所有專案開發計畫，從初期規劃到後續版本的迭代計畫。
*   **[Research_Reports/](./Research_Reports/)**: 存放所有研究與分析報告，包括概念性驗證（PoC）報告、市場分析和最終研究成果。
*   **[System_Documentation/](./System_Documentation/)**: 包含所有系統級文件，例如工具使用說明、代理程式（Agent）設定指南和系統日誌格式。
