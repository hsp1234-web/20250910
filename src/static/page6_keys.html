金鑰管理

此頁面用於管理您的 Google API 金鑰池。有效的金鑰將被用於 AI 分析任務。

金鑰輸入模式

新增金鑰 (手動)

說明：若貼上多個金鑰，別名只會套用於第一個金鑰。

從授權來源載入 (自動)

此模式會嘗試從伺服器環境變數中讀取名為 GOOGLE_API_KEY, GOOGLE_API_KEY_1... 的金鑰。

全域 API 行為設定

設定所有對外部 API (Google Gemini, Yahoo Finance) 請求的等待上限。過低可能導致正常請求失敗，過高可能在網路問題時造成長時間等待。

當 API 請求遭遇暫時性錯誤時，在放棄前的最大重試次數。

API 請求延遲設定

在批次啟動 AI 分析時，每個任務之間的提交間隔時間。有助於避免瞬間請求過多導致 API 壅塞。

當一個金鑰因配額用盡而失敗時，在嘗試下一個金鑰前的等待時間。有助於減緩金鑰池的消耗速度。
