# `src/static` 目錄說明文件

此目錄存放所有前端靜態 HTML 檔案。以下為各檔案的功能簡介。

| 檔案名稱                      | 頁面標題/功能                               | 簡介                                             |
| ----------------------------- | ------------------------------------------- | ------------------------------------------------ |
| `main.html`                   | 鳳凰主頁                                    | 系統的主要入口頁面，提供所有功能模組的導覽連結。 |
| `mp3.html`                    | 音訊轉錄                                    | 提供上傳 MP3 檔案並進行語音轉文字的功能。      |
| `page1.html`                  | 文件分析                                    | 文件分析功能的主頁面。                           |
| `page_bond.html`              | 債券分析                                    | 債券相關數據分析與視覺化頁面。                   |
| `primary_dealer_analysis.html`| 一級交易商分析                              | 提供美國一級交易商相關數據的分析與圖表。         |
| `page6_keys.html`             | 金鑰管理                                    | 用於管理、新增或刪除系統所需的 API 金鑰。        |
| `essay_performance.html`      | 小作文績效                                  | (建置中) 用於分析「小作文」績效的功能頁面。    |
| `history.html`                | 歷史紀錄                                    | 顯示系統操作或處理歷史的頁面。                   |
| `interactive_chart.html`      | 互動式圖表                                  | 用於顯示和操作互動式數據圖表。                   |
| `json_viewer.html`            | JSON 檢視器                                 | 提供一個介面來格式化並檢視 JSON 數據。           |
| `line_extractor.html`         | 行提取器                                    | 從文本中提取特定行的工具頁面。                   |
| `report_viewer.html`          | 報告檢視器                                  | 用於顯示生成的分析報告。                         |
| `prompts.html`                | 提示詞管理                                  | 管理與 AI 互動時使用的提示詞 (Prompts)。         |
| `page2_downloader.html`       | 下載器                                      | 提供檔案下載功能的頁面。                         |
| `page3_processor.html`        | 處理器                                      | 執行特定數據處理任務的介面。                     |
| `page4_summary_center.html`   | 摘要中心                                    | 多階段任務的摘要與總覽頁面。                     |
| `page5_backup.html`           | 備份管理                                    | 用於建立或還原系統備份。                         |
| `page7_prompts.html`          | 提示詞管理 (P7)                             | 另一個用於管理提示詞的介面。                     |
| `page8_file_details.html`     | 檔案詳情                                    | 顯示特定檔案的詳細資訊。                         |
| `page9_dashboard.html`        | 儀表板                                      | 系統狀態或數據的綜合儀表板。                     |
| `page10_service_test.html`    | 服務測試                                    | 用於開發者測試後端服務狀態的頁面。               |
| `_processed_file_item.html`   | (模板) 已處理檔案項目                       | 用於動態生成已處理檔案列表的 HTML 片段。         |
| `export_cards.html`           | (模板) 匯出卡片                             | 用於以卡片形式匯出數據的模板。                   |
| `export_table.html`           | (模板) 匯出表格                             | 用於以表格形式匯出數據的模板。                   |
| `page1_sub_*.html`            | (子頁面) 文件分析相關                       | 文件分析功能下的各個子頁面 (總覽、匯入、匯出)。 |
| `page4_stage*.html`           | (子頁面) 多階段任務                         | 一個多階段處理流程中的各個步驟頁面。             |
